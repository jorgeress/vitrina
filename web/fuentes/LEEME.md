# Fuentes de las tarjetas

Las tarjetas para compartir cada ficha (`tarjetas/*.png`) se pintan al
construir la web, y ahí no hay navegador que baje las fuentes de Google: van
aquí, las mismas de la casa.

- `Cinzel.ttf`, de The Cinzel Project Authors.
- `SourceSans3.ttf` y `SourceSans3-Italic.ttf`, de Adobe.

Las dos bajo la SIL Open Font License 1.1 (`OFL-*.txt`), sacadas de
[google/fonts](https://github.com/google/fonts) tal cual.
